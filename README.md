# APP testWork ▌ React + TypeScript + Vite

INSTRUCCIONES DE EJECUCIÓN DE LA APP 
- Para ejecutar la app en Visual studio code se debe de instalar la herramienta de compilación "Vite" , Enlace del plugin https://marketplace.visualstudio.com/items/?itemName=antfu.vite. Puede instalar el compilador por NPM con la siguiente instrucción: $ npm create vite@latest
- El puerto utilizado en Visual Studio con Vite es el 4000
- URL http://localhost:4000
- Se creo un archivo Mock de autenticación para simular la verificación de usuarios. En el archivo, "authMock.ts", se puede visualizar los usuarios con password y contraseña.
- Utilice: email: "test@example.com", password: "password123", o cualquier otro de los usuarios del archivo Mock.

FILOSOFIA DE DESARROLLO Y COMPLICACIONES ENCONTRADAS.
